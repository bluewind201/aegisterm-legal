English

1. Overview & Zero Telemetry

AegisTerm is an offline-first desktop workspace for Windows system and network engineers. The publisher (wonwoo lee) does not operate any backend server, analytics SDK, ad network, or telemetry service, and does not collect, sell, or share your personal data.

2. Local-Only Storage

  • Saved session profiles, folder hierarchy, and application settings are stored strictly on your local Windows device.
  • Sensitive credentials (passwords, SSH keys, IAM keys) are encrypted locally with your master password using Argon2id and AES-256-GCM.
  • Session logs, encrypted command history, and SFTP file transfers occur only when explicitly enabled or started by you.
  • Temporary Windows Credential Manager entries created for RDP launches are cleared automatically after the short launch lease expires.

3. Optional & User-Initiated Network Connections

  • Public IP Lookup (Off by Default): Disabled out of the box (publicIp: false). Only if you manually enable it in Settings will the app contact Cloudflare (1.1.1.1) or fallback api.ipify.org directly from your device to show your public IP in the status bar.
  • WHOIS / ASN Lookups: Initiated solely on user action against IANA, regional internet registries, or Team Cymru.
  • AWS Management & Remote Hosts: SSH, Telnet, SFTP, Serial, RDP, SNMP, IPMI, Proxmox, Docker, Kubernetes, SQL database, HTTP testing, TFTP/Syslog servers, BMC consoles, and AWS CLI integrations connect directly only to targets and services you specify.

4. Microsoft Store & Updates

Purchases, license verification, and updates via Microsoft Store are governed by the Microsoft Privacy Statement.

5. Contact

Questions about this Privacy Policy may be sent to bluewind201@naver.com.

한국어

1. 개요 및 무수집(Zero Telemetry) 원칙

AegisTerm(이지스텀)은 Windows 시스템·네트워크 엔지니어를 위한 로컬 우선 데스크톱 작업 공간입니다. 게시자(wonwoo lee)는 원격 수집 서버, 분석 SDK, 광고 모듈, 텔레메트리를 일절 사용하지 않으며 사용자의 개인정보를 수집·판매·제공하지 않습니다.

2. 사용자 기기 로컬 저장 데이터

  • 접속 프로필, 폴더 구조, 화면 및 터미널 설정은 사용자 Windows 기기 내부에만 저장됩니다.
  • 암호, SSH 키, IAM 키 등 자격 증명은 사용자 마스터 암호(Argon2id + AES-256-GCM)로 로컬 금고에 암호화 저장됩니다.
  • 세션 로그, 명령 기록(금고 암호화), SFTP 파일 전송은 사용자가 직접 활성화하거나 실행할 때만 처리됩니다.
  • RDP 실행 시 등록되는 Windows 자격 증명 관리자 임시 항목은 짧은 실행 유지 시간 후 자동 삭제됩니다.

3. 선택적·사용자 실행 네트워크 통신

  • 공인 IP 표시(기본 비활성화): 기본 설정에서는 꺼져 있습니다(publicIp: false). 사용자가 설정에서 직접 켠 경우에만 상태 줄 표시용으로 Cloudflare(1.1.1.1) 또는 api.ipify.org에 직접 요청합니다.
  • WHOIS / ASN 조회: 사용자가 직접 조회를 실행할 때만 IANA, 지역 인터넷 등록기관, Team Cymru로 직접 통신합니다.
  • 원격 장비·AWS 연동: SSH, Telnet, SFTP, Serial, RDP, SNMP, IPMI, Proxmox, Docker, Kubernetes, DB, HTTP 요청, TFTP/Syslog 서버, BMC 웹 콘솔, AWS CLI 기능은 사용자가 지정한 대상 및 서비스와만 직접 통신합니다.
